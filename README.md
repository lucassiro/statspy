# statspy
A Statistics and Machine Learning library made with pure Python.  
Made for study purposes.

### Main concepts
- Done without using AI
- Done without using external libraries (only for testing and comparing results)
- Uses only native Python data types
- Focus on implementation from scratch, performance is not the goal (although desired)
